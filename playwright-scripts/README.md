# playwright-scripts

## `create-applications`
>**Important**: Before running this script, ensure your fee lines are all set to 0 so that submitting applications is free. We want to avoid spamming gov.uk pay

Will create a lot of flare, vent and production applications which are ready to grant and issue


## bun

```bash
bun install && bun create-applications
```

## npm

```bash
npm install && npm create-applications
```
